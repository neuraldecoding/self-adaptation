Komodo Mlipir Algorithm (KMA) version 1.0.0

Developed in MATLAB R2017a based on the following paper:

S. Suyanto, A.A. Ariyanto, A.F. Ariyanto, Komodo Mlipir Algorithm 
Applied Soft Computing, 2021, 108043, https://doi.org/10.1016/j.asoc.2021.108043

Updated 23 November 2021 by Prof. Dr. Suyanto, S.T., M.Sc.

How to use the source code:

1. Open in Matlab R2017a or other compatible versions.
2. Run Main2D.m to get the optimum solution to a benchmark function (defined by FunctionID and Dimension) with two-dimensional visualization of KMA evolution.
3. Run Main3D.m to get the optimum solution to a benchmark function (defined by FunctionID and Dimension) with three-dimensional visualization of KMA evolution.
